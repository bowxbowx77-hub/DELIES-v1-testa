# HTTP API

Префікс `/api`. Дані повертаються у JSON, окрім файлових вкладень. Час — Unix timestamp у мілісекундах UTC. Репозиторій має незалежний від імені 128-бітний ID. URL окремої сторінки: `/r/<id>`. В UI файли завжди відображаються як текст/дані, а не як вебсторінки користувача.

Запити автентифікуються через cookie `dv_session`. **Усі запити зі змінами**, включаючи старт гостьової сесії й вхід, вимагають заголовок `X-DevVault-Request: workspace`. Для JSON передавайте `Content-Type: application/json`. Cross-origin браузерний API не відкривається.

## Сесія та обліковий запис

| Метод   | Маршрут             | Призначення                                                                                                   |
| ------- | ------------------- | ------------------------------------------------------------------------------------------------------------- |
| `GET`   | `/health`           | Доступність API і SQLite.                                                                                     |
| `GET`   | `/session`          | `{workspace: null}` для аноніма або існуючий простір; нічого не створює.                                      |
| `POST`  | `/session/start`    | Відкрити власну сесію; для нового браузера створити гостьовий простір.                                        |
| `GET`   | `/workspace`        | Поточний користувач, репозиторії, останні події, квота, використане місце, лічильники кошика і непрочитаного. |
| `POST`  | `/auth/register`    | `{name, email, password}`. Перетворити гостьовий акаунт на постійний, не втрачаючи проєкти.                   |
| `POST`  | `/auth/login`       | `{email, password}`. Створити нову сесію існуючого акаунта.                                                   |
| `POST`  | `/auth/logout`      | Відкликати поточну сесію.                                                                                     |
| `PATCH` | `/account`          | `{name, color}`. Оновити профіль; email не публікується.                                                      |
| `POST`  | `/account/password` | `{current, password}`. Потрібен поточний пароль; інші сесії відкликаються.                                    |

## Репозиторії

| Метод    | Маршрут                | Призначення                                                                                                                                     |
| -------- | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET`    | `/public?q=…&offset=0` | Пошук опублікованих репозиторіїв. До 48 записів і прапорець `more`. Каталог не дублює чужі незмінені стартові проєкти незареєстрованих гостей.  |
| `POST`   | `/repos`               | `{name, description?, visibility?, license?, style?, readme?}` → `201 {id}`.                                                                    |
| `GET`    | `/repos/:id?version=N` | Метадані, `owner` (право редагування), версії, вибраний номер та список `{path,size}`. `visit=1` враховує відкриття сторінки стороннім читачем. |
| `PATCH`  | `/repos/:id`           | Часткове оновлення назви, опису, ліцензії, іконки або видимості.                                                                                |
| `DELETE` | `/repos/:id`           | Перемістити до кошика і закрити доступ до всіх версій.                                                                                          |
| `GET`    | `/trash`               | Кошик поточного користувача.                                                                                                                    |
| `POST`   | `/repos/:id/restore`   | Відновити репозиторій з кошика разом з попередньою видимістю.                                                                                   |
| `DELETE` | `/repos/:id/purge`     | Тільки з кошика. `{confirm: "точна-назва"}`. Видалити всі версії та блоби без інших посилань.                                                   |

`visibility`: `private` (типово) або `public`. `style`/`color`: `violet`, `lime`, `blue`, `amber`, `rose`, `cyan`. Поле ліцензії підтримує `MIT`, `Apache-2.0`, `BSD-3-Clause`, `GPL-3.0-only`, `Unlicensed`. Це метадані: вміст власного файлу `LICENSE` завантажується окремо. Назва репозиторію 1–64 символи, починається з латинської літери чи цифри; далі дозволено також крапку, дефіс, підкреслення. В межах акаунта назва унікальна, включаючи кошик.

## Файли й версії

| Метод  | Маршрут                            | Призначення                                                                                                                                                                                                             |
| ------ | ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `POST` | `/repos/:id/upload`                | `multipart/form-data`, одне або кілька полів `files`; необов’язкові `paths` (масив відносних шляхів у JSON в тому самому порядку), `message` та `base`. ZIP розпаковується на сервері. Відповідь `201 {number, files}`. |
| `GET`  | `/repos/:id/file?path=…&version=N` | `{text, truncated, size, path}`. `text: null` для двійкового вмісту. Текстовий перегляд обмежено 96 KiB. `download=1` повертає вкладення.                                                                               |
| `POST` | `/repos/:id/files`                 | `{operation: "rename", path, target, base}` або `{operation: "delete", path, base}`. Створює знімок зі зміною.                                                                                                          |
| `POST` | `/repos/:id/restore-version`       | `{number, base}`. Відновлює маніфест вибраної версії як наступну версію.                                                                                                                                                |
| `GET`  | `/repos/:id/download?version=N`    | Отримати ZIP із збереженими відносними шляхами. Без `version` — поточний знімок.                                                                                                                                        |

`base` — номер останньої відомої версії. Якщо проєкт тим часом змінився, повертається `409`, а не перезаписуються нові дані. Шляхи у query string треба URL-кодувати. Зміни файлів доступні тільки власнику; публічність дає право читання, але не запису.

```js
// Приклад для вже відкритого власного workspace, у тому самому origin.
async function createRepository(name) {
  const response = await fetch('/api/repos', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-DevVault-Request': 'workspace',
    },
    body: JSON.stringify({ name, visibility: 'private', readme: true }),
  });
  const result = await response.json();
  if (!response.ok) throw new Error(result.error);
  return result.id;
}
```

## Журнал, сповіщення, помилки

`GET /events?kind=upload&before=<id>` повертає `{events, more}` (до 50 подій у зворотному порядку). `kind` та `before` необов’язкові; `unread=1` фільтрує непрочитані події перед пагінацією. `POST /events/read` позначає сповіщення поточного користувача прочитаними.

Помилки API мають форму `{"error":"людинозрозумілий опис"}`. Типові коди: `400` валідація, `401` немає сесії, `403` заборонений запит, `404` неіснуючий або недоступний репозиторій, `409` конфлікт імені чи версії, `413` ліміт, `429` надто багато запитів, `503` недоступне сховище/сканер. Дані невдалої операції не стають новою версією.

## Pocket 1.1 (Android)

`POST /api/mobile/register` (`name,email,password`, 201), `/api/mobile/login` (`email,password`, 200) повертають `{token,expires,user}` без cookie. `expires` — Unix milliseconds. `POST /api/mobile/logout` відкликає поточний bearer. Для клієнта: `Authorization: Bearer dvm_…`, `X-DevVault-Client: pocket`, `X-DevVault-Request: workspace`; паролі й токени не передаються в URL. Єдиний cross-origin grant для цих даних — `https://pocket.devvault.invalid` на визначених маршрутах, без credentials/cookie. Усі перевірки власника та видимості діють також для Pocket.

Мобільний `POST /api/repos/<id>/upload` може додати multipart `snapshot_visibility=private|public` та обов’язковий `base`. Це режим повної заміни маніфесту: нова версія та видимість фіксуються однією транзакцією після перевірки файлів і конфлікту. Потребує bearer власника, повертає `{number,files,snapshot:true}`. Звичайні вебзавантаження без цього поля, як раніше, об’єднують зміни з поточною версією.
