## DEVVAULT Pocket 1.1.0

Інсталяційний APK для Android 8.0+ (API 26), з актуальним Android System WebView / Chrome 110+. Пакет **`org.devvault.pocket`**, versionCode **10100**. Не потрібно підключати сервер для запуску чи зберігання файлів.

- **На пристрої:** проєкти, ZIP зі структурою каталогів, окремі файли, редактор малих текстових файлів, історія знімків, відновлення, пошук, журнал, кошик, експорт ZIP і резервна копія `.dvault` з історією.
- **На вашому HTTPS-сервері:** реєстрація і вхід, перегляд і завантаження репозиторіїв. Передавання — лише вручну через «На сервер». Вибір «Приватний» або «Публічний», оновлення прив’язаної копії без зміни її адреси `/r/<id>`. Спільний сервер або сторонній ключ у реліз не вбудовано.
- **Перевірка імпорту:** скомпільований C++ модуль перевіряє шляхи, типи й ліміти. Код проєктів не запускається. При видаленні застосунку Android видаляє його приватні дані: спочатку збережіть `.dvault` за межами застосунку.

**Встановлення:** завантажте `DEVVAULT-Pocket-1.1.0.apk`, звірте SHA-256 із `SHA256SUMS.txt`, відкрийте APK на телефоні. Дозвіл «Встановлювати невідомі застосунки» потрібен лише для обраного джерела встановлення. Сертифікат SHA-256: `1FD9ACF5D9A447692EF7FFC1DA6C920C7823FA39DA1E79A519350E1234CA130B`.

**Матеріали:** APK, контрольні суми, публічний сертифікат і протокол `apksigner`, архів повного вихідного коду й patch до вебверсії `547b973`. Інструкції збірки, оновлення та розгортання HTTPS-сервера — `docs/ANDROID.md` та `docs/OPERATIONS.md` у вихідному коді. Власні документи користувачів не входять до релізу.
